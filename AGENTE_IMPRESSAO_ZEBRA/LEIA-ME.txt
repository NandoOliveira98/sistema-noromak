NOROMAK PRINT AGENT 1.0
========================

Finalidade
----------
Imprime ZPL diretamente na impressora Zebra instalada no Windows, sem QZ Tray e sem janelas de autorização.

Instalação (uma vez no computador da Zebra)
--------------------------------------------
1. No sistema Web, entre como Admin e abra a aba "Agente Zebra".
2. Copie o token de conexão.
3. Extraia este ZIP inteiro.
4. Execute CONFIGURAR_AGENTE_IMPRESSAO.bat.
5. Informe o token e confirme o nome exato da impressora.
6. Volte ao sistema Web e faça uma impressão de teste.

O agente fica em:
%LOCALAPPDATA%\NoromakPrintAgent

Ele inicia automaticamente quando o usuário entra no Windows.
O log fica em:
%LOCALAPPDATA%\NoromakPrintAgent\agent.log

Arquivos auxiliares
-------------------
INICIAR_AGENTE.bat  - inicia manualmente.
PARAR_AGENTE.bat    - encerra o agente.
ABRIR_LOG.bat       - abre o arquivo de diagnóstico.
DESINSTALAR_AGENTE.bat - remove o agente do usuário atual.

Segurança
---------
O agente usa HTTPS e um token exclusivo gerado pelo servidor. Ele só recebe trabalhos ZPL da fila da Expedição.
O token pode ser renovado pelo Admin; ao renovar, execute o configurador novamente.
