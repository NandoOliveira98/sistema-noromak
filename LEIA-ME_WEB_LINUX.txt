SISTEMA DE CONFERÊNCIA NOROMAK — WEB/LINUX 8.2
================================================

Esta versão retorna à impressão pelo QZ Tray e remove o uso do Noromak Print Agent.

PUBLICAR
--------
Copie estes arquivos para a pasta atual do projeto, preservando a pasta oculta .git.
Depois execute:

  git add -A
  git commit -m "retorna impressao para o QZ Tray"
  ./publicar.sh

Não execute instalar_servidor_uma_vez.sh e não altere /etc/systemd quando a infraestrutura já estiver pronta.

COMPUTADOR DA IMPRESSORA
------------------------
1. Execute DESINSTALAR_AGENTE_ZEBRA_ANTIGO.bat se o agente da versão 8.0 tiver sido instalado.
2. Instale/abra o QZ Tray.
3. Execute CONFIGURAR_QZ_TRAY_WEB.bat uma única vez no usuário do Windows que imprime.
4. Feche e abra novamente o navegador.
5. Na Conferência, informe o nome exato da impressora, normalmente:
   ZDesigner ZD220-203dpi ZPL

A Conferência não abre conexão com o QZ Tray durante o login. A conexão ocorre somente ao testar ou imprimir.

SERVIDOR
--------
Aplicação: 127.0.0.1:8100
Caminho: /expedicao
Banco: /home/expedicao/dados/expedicao.db
Backups: /home/expedicao/backups
Chave privada QZ: /home/expedicao/qz/qz-private-key.pem

A publicação não substitui o banco permanente.


EXTENSÃO MERCADO LIVRE
-----------------------
A versão 8.2 aceita capturas enviadas pela extensão própria Noromak. A extensão é instalada separadamente no Chrome do computador do Admin. Mantenha o Painel Admin aberto e autenticado.
