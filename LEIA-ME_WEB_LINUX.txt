SISTEMA DE CONFERÊNCIA NOROMAK — WEB/LINUX 10.2
================================================

Esta versão mantém:
- Noromak Admin instalável
- Noromak Conferência instalável
- Conferência vertical no celular e leitura por câmera
- Importação direta de Mercado Livre, Shopee e Magalu pela extensão
- Fila de impressão e histórico

E substitui o QZ Tray pelo Noromak Print Service:

  CELULAR/COMPUTADOR -> SERVIDOR WEB -> ESTAÇÃO DE IMPRESSÃO
  -> NOROMAK PRINT SERVICE -> FILA RAW DO WINDOWS -> ZEBRA USB

Não existe janela Allow e nenhuma confirmação é exigida por etiqueta.

PUBLICAR
--------
Copie estes arquivos para a pasta atual do projeto, preservando a pasta oculta .git.
Depois execute:

  git add -A
  git commit -m "adiciona Noromak Print Service"
  ./publicar.sh

Não execute instalar_servidor_uma_vez.sh e não altere /etc/systemd quando a infraestrutura já estiver pronta.
O banco permanente é preservado.

COMPUTADOR CONECTADO À ZEBRA
----------------------------
1. Abra a pasta:
   FERRAMENTAS_WINDOWS/NOROMAK_PRINT_SERVICE_ZEBRA_V2_0
2. Execute CONFIGURAR_NOROMAK_PRINT_SERVICE.bat.
3. Selecione a Zebra na lista de impressoras.
4. Confirme a impressão de teste.
5. Acesse:
   https://noromakweb.com.br/expedicao/estacao-impressao
6. Entre uma vez com um usuário do estoque.
7. Deixe a Estação Zebra aberta.

O programa local inicia automaticamente com o Windows.
A página da estação também é aberta automaticamente no login do Windows.

CONFERÊNCIA PELO CELULAR
------------------------
1. Abra https://noromakweb.com.br/expedicao/conferencia.
2. Entre com o usuário do operador.
3. Selecione o pedido e use o botão ESCANEAR CÓDIGO.
4. Ao finalizar, a etiqueta entra na fila.
5. A Estação Zebra entrega o ZPL ao programa local.
6. O pedido só sai dos pendentes depois que o envio RAW à Zebra for confirmado.

DIAGNÓSTICO DO COMPUTADOR DA ZEBRA
----------------------------------
Status local: http://127.0.0.1:18181/
Log: %LOCALAPPDATA%\NoromakPrintService\service.log
Configuração: %LOCALAPPDATA%\NoromakPrintService\config.json

SERVIDOR
--------
Aplicação: 127.0.0.1:8100
Caminho: /expedicao
Banco: /home/expedicao/dados/expedicao.db
Backups: /home/expedicao/backups

O Noromak Print Service não acessa o servidor diretamente. A página autenticada
/expedicao/estacao-impressao faz a ponte com o serviço local em 127.0.0.1.
Por isso não é necessário liberar uma rota sem login no nginx.
