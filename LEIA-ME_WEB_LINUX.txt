SISTEMA DE CONFERÊNCIA NOROMAK — WEB/LINUX 9.0
================================================

Esta versão mantém:
- Noromak Admin instalável
- Noromak Conferência instalável
- QZ Tray no computador conectado à Zebra
- Importação dos marketplaces

E mantém a impressão iniciada pelo celular:

  CELULAR -> SERVIDOR WEB -> ESTAÇÃO DE IMPRESSÃO -> QZ TRAY -> ZEBRA USB

PUBLICAR
--------
Copie estes arquivos para a pasta atual do projeto, preservando a pasta oculta .git.
Depois execute:

  git add -A
  git commit -m "adiciona modo vertical e camera no celular"
  ./publicar.sh

Não execute instalar_servidor_uma_vez.sh e não altere /etc/systemd quando a infraestrutura já estiver pronta.
A atualização cria automaticamente as tabelas da fila no mesmo SQLite permanente.

COMPUTADOR CONECTADO À ZEBRA
----------------------------
1. Deixe a Zebra conectada por USB e o QZ Tray aberto.
2. Abra:
   https://noromakweb.com.br/expedicao/estacao-impressao
3. Entre com um usuário do estoque.
4. Confirme o nome da impressora, normalmente:
   ZDesigner ZD220-203dpi ZPL
5. Clique em "Testar Zebra".
6. Clique em "Iniciar estação".
7. Deixe a Estação de Impressão aberta durante as conferências pelo celular.

A Estação pode ser instalada como aplicativo separado pelo botão "Instalar Estação".

CONFERÊNCIA PELO CELULAR
------------------------
1. Abra:
   https://noromakweb.com.br/expedicao/conferencia
2. Entre com o usuário do operador.
3. Selecione o pedido e toque em "ESCANEAR CÓDIGO".
4. Autorize a câmera na primeira utilização.
5. Aponte a câmera traseira para o código de barras; a leitura entra no mesmo fluxo da bipagem.
6. Também é possível digitar o código manualmente no campo numérico.
7. Ao finalizar, a etiqueta entra na fila do servidor.
8. A Estação imprime na Zebra e confirma o resultado ao celular.
9. O pedido só sai dos pendentes após a confirmação da impressão.

Se o computador estiver desligado ou a Estação estiver parada, o pedido permanece conferido e aguardando impressão. Depois de iniciar a Estação, use "Verificar impressão" no celular.

IMPRESSÃO NO COMPUTADOR
-----------------------
A Conferência aberta no próprio computador da Zebra continua tentando imprimir diretamente pelo QZ Tray. Se o QZ local não estiver disponível, ela usa automaticamente a Estação de Impressão.

SERVIDOR
--------
Aplicação: 127.0.0.1:8100
Caminho: /expedicao
Banco: /home/expedicao/dados/expedicao.db
Backups: /home/expedicao/backups
Chave privada QZ: /home/expedicao/qz/qz-private-key.pem

A publicação não substitui o banco permanente.

IMPRESSAO AUTOMATICA PELO CELULAR (9.3)
---------------------------------------
No computador conectado a Zebra, execute uma unica vez:
CONFIGURAR_ESTACAO_IMPRESSAO_AUTOMATICA.bat
A Estacao Zebra e o QZ Tray passarao a abrir automaticamente com o Windows.
