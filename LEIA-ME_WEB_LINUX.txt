SISTEMA DE CONFERÊNCIA NOROMAK — WEB/LINUX 8.0
================================================

Esta versão roda no servidor Linux em 127.0.0.1:8100, no caminho /expedicao.
A infraestrutura systemd/nginx já é administrada pelo responsável do servidor.

PUBLICAÇÃO
----------
Na pasta do projeto que contém a pasta oculta .git:

git add -A
git commit -m "versao 8.0 com agente de impressao Zebra"
./publicar.sh

Não execute instalar_servidor_uma_vez.sh e não altere /etc/systemd.

IMPRESSÃO ZEBRA SEM QZ TRAY
---------------------------
A impressão é realizada pelo Noromak Print Agent instalado no computador ligado à Zebra.
O navegador envia o ZPL ao servidor. O agente busca o trabalho por HTTPS e o entrega diretamente
à fila RAW da impressora do Windows.

Instalação no computador da Zebra:
1. Entre no sistema como Admin.
2. Abra a aba "Agente Zebra".
3. Copie o token e baixe o programa completo.
4. Extraia o ZIP e execute CONFIGURAR_AGENTE_IMPRESSAO.bat.
5. Informe o token e o nome exato da impressora instalada.
6. Faça uma impressão de teste.

O agente fica em %LOCALAPPDATA%\NoromakPrintAgent e inicia com o Windows.
Não é necessário instalar Python, QZ Tray ou certificados.
