SISTEMA DE CONFERÊNCIA NOROMAK — WEB/LINUX 8.6
================================================

Esta versão mantém o QZ Tray e adiciona dois aplicativos PWA instaláveis e separados:
- Noromak Admin
- Noromak Conferência

PUBLICAR
--------
Copie estes arquivos para a pasta atual do projeto, preservando a pasta oculta .git.
Depois execute:

  git add -A
  git commit -m "adiciona aplicativos instalaveis admin e conferencia"
  ./publicar.sh

Não execute instalar_servidor_uma_vez.sh e não altere /etc/systemd quando a infraestrutura já estiver pronta.

INSTALAR OS APLICATIVOS
-----------------------
Administração:
  https://noromakweb.com.br/expedicao/admin
  Clique em "Instalar Admin".

Conferência:
  https://noromakweb.com.br/expedicao/conferencia
  Clique em "Instalar Conferência".

Cada aplicativo recebe nome, ícone e janela próprios no Windows. Eles continuam usando o mesmo servidor, banco de dados e usuários do estoque.

COMPUTADOR DA IMPRESSORA
------------------------
1. Instale/abra o QZ Tray.
2. Execute CONFIGURAR_QZ_TRAY_WEB.bat uma única vez no usuário do Windows que imprime.
3. Na Conferência, use a impressora normalmente configurada, por exemplo:
   ZDesigner ZD220-203dpi ZPL

A Conferência conecta ao QZ Tray somente ao testar ou imprimir.

SERVIDOR
--------
Aplicação: 127.0.0.1:8100
Caminho: /expedicao
Banco: /home/expedicao/dados/expedicao.db
Backups: /home/expedicao/backups
Chave privada QZ: /home/expedicao/qz/qz-private-key.pem

A publicação não substitui o banco permanente.

EXTENSÃO DE MARKETPLACES
------------------------
A extensão Noromak Importador de Marketplaces continua separada e pode ler pedidos do Mercado Livre, Shopee e Magalu no computador do Admin.
