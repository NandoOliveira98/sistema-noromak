Pedidos pendentes

      
Funcionamento: preencha as linhas como no Excel. O marketplace é reconhecido pelo número do pedido. Nas vendas do Mercado Livre, o prefixo 20000 fica oculto nas telas, mas é mantido internamente para localizar a etiqueta correta. Ao informar SKU ou EAN, o restante é preenchido pelo banco de produtos. Quando o conferente finaliza e imprime o pedido, todas as linhas desse pedido são salvas no histórico e desaparecem automaticamente desta tabela.

      

        📥 Importar a planilha de pedidos
        Selecione o mesmo arquivo Excel que você já utiliza. A aba PEDIDOS será lida, o marketplace será reconhecido pelo número do pedido e os dados ausentes serão completados pelo banco de produtos. Pedidos já existentes serão atualizados sem apagar o andamento da conferência. A coluna Data do Pedido é aceita. Para pedidos com kit importados por imagem, marque Este pedido é um kit dentro da tela Importar por print. No Excel, continuam disponíveis as colunas Kit, Nome do Kit, Quantidade de Kits e Quantidade por Kit.
