V17.40 - PROMOÇÕES: MLB -> SKU DO MERCADO LIVRE -> ESTOQUE APOLLO

Base: V17.39.

ALTERAÇÃO PRINCIPAL
- Na tela Precificador > Promoções vencidas e a vencer, o botão "Atualizar estoque ML + Apollo" usa o MLB da linha para consultar o próprio anúncio na API do Mercado Livre.
- O SKU é lido do seller_custom_field / atributo SELLER_SKU do anúncio.
- Para anúncios marcados como "Estoque zerado", o SKU exato retornado pelo ML é consultado no Apollo pelo endpoint já existente do servidor.
- A coluna ESTOQUE mostra: estoque marcado, SKU encontrado no ML, estoque Apollo, estoque por filial quando disponível e aviso "REVISAR PROMOÇÃO" quando Apollo > 0.
- Se o ML não devolver SKU, mostra "SKU não encontrado no anúncio ML".
- Se Apollo falhar, mostra erro/estoque indisponível sem assumir zero.

DESEMPENHO / SEGURANÇA
- Não depende de vínculo MLB<->SKU do Precificador.
- Não abre novas abas.
- Não consulta Apollo para todos os anúncios; somente para os marcados como estoque zerado dentro do lote solicitado pelo botão de atualização.
- Mantém cache local de metadados/resultado para exibição e só força nova consulta quando o usuário clica em Atualizar estoque.
- Nenhuma alteração em Shopee, Conferência, etiquetas ou cálculos do Precificador.
