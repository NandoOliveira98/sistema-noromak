NOROMAK PRINT SERVICE PARA ZEBRA - VERSAO 2.0
==============================================

OBJETIVO
- Imprimir etiquetas ZPL diretamente na Zebra pelo spooler RAW do Windows.
- Nao utiliza QZ Tray.
- Nao exibe Allow, Remember ou qualquer confirmacao por etiqueta.
- Permite que a conferencia seja concluida pelo celular.

COMO INSTALAR
1. Extraia o ZIP inteiro em uma pasta.
2. Execute CONFIGURAR_NOROMAK_PRINT_SERVICE.bat.
3. Escolha a impressora Zebra na lista.
4. Aceite a etiqueta de teste.
5. A pagina Estacao Zebra sera aberta. Entre uma vez com o usuario do estoque.
6. Deixe a Estacao Zebra aberta no computador conectado por USB a impressora.

FUNCIONAMENTO
Celular -> sistema Web -> fila do servidor -> pagina Estacao Zebra autenticada
-> programa local em 127.0.0.1:18181 -> fila RAW do Windows -> Zebra.

POR QUE ESTA VERSAO NAO PRECISA DE ROTA PUBLICA NO NGINX
O programa local nao acessa diretamente o servidor. A pagina da Estacao Zebra,
ja autenticada no NoromakWeb, busca os trabalhos e os entrega ao programa local.

DIAGNOSTICO
- Status: http://127.0.0.1:18181/
- Log: %LOCALAPPDATA%\NoromakPrintService\service.log
- Configuracao: %LOCALAPPDATA%\NoromakPrintService\config.json

REQUISITOS
- Windows 10/11 x64.
- Driver da Zebra instalado e impressora visivel no Windows.
- Computador ligado e pagina Estacao Zebra aberta.
- Chrome ou Edge logado no sistema.
