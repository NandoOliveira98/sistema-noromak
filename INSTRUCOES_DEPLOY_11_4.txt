ATUALIZAÇÃO NOROMAK EXPEDIÇÃO 11.4 — DEPLOY
============================================

O ZIP é uma atualização por sobreposição. Ele não contém banco SQLite, .env,
backups, segredos do QZ, arquivos de migração nem a pasta .git.

1. Na máquina usada para publicar, confirme o estado do projeto:

   git status

2. Extraia o conteúdo do ZIP dentro da pasta atual do projeto, preservando a
   pasta .git e o arquivo .env da instalação.

3. Confira e publique:

   git status --short
   git --no-pager diff --stat
   git add -A
   git commit -m "corrige etiqueta termica Shopee por QR"
   ./publicar.sh

4. Verifique a aplicação:

   ssh expedicao "curl -fsS http://127.0.0.1:8100/expedicao/api/health"
   ./verificar_servidor.sh

   A API deve responder com version 11.4.

5. Faça Ctrl+F5 em:

   https://noromakweb.com.br/expedicao/admin
   https://noromakweb.com.br/expedicao/conferencia

6. Validação rápida com uma etiqueta Shopee:

   - envie o arquivo .txt na aba Etiquetas;
   - se o pedido tiver rastreio importado, o vínculo será automático;
   - se o pedido ainda não tiver rastreio, confira a prévia que será aberta;
   - com um único pedido, ele já estará selecionado: clique em Confirmar vínculos;
   - confirme que a etiqueta aparece como Vinculada e permanece armazenada.

Para completar pedidos antigos automaticamente, reimporte o relatório Shopee
que contenha a coluna Número de rastreamento antes de processar as etiquetas.

Não execute instalar_servidor_uma_vez.sh em uma VPS já configurada.
