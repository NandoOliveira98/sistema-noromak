VERSÃO 14.3 — PEDIDOS MANUAIS TAMBÉM RECEBEM ETIQUETA AUTOMÁTICA

CORREÇÃO PRINCIPAL
- Pedidos Mercado Livre adicionados por PRINT ou EXTENSÃO agora são reconciliados
  automaticamente com o order_id e shipment_id reais da API.
- Reconhece o número de venda visível mesmo quando o order_id da API possui o
  prefixo técnico 20000.
- Exemplo:
  print: 18159171928
  API:   2000018159171928
  => o sistema reconhece como o mesmo pedido.

FLUXO
- A VPS procura pedidos manuais Mercado Livre que ainda não possuem vínculo API.
- A cada 60 segundos, pesquisa pedidos pagos recentes do seller (últimos 7 dias).
- Quando encontra correspondência:
  * preserva o pedido já existente;
  * vincula VendaMercadoLivre;
  * vincula PackIdMercadoLivre;
  * vincula ShipmentIdMercadoLivre;
  * troca o Pedido para o identificador operacional da API;
  * atualiza nome fiscal, SKU/kit, prazo e rastreio;
  * entra imediatamente no mesmo fluxo automático de etiqueta.
- Se a etiqueta já estiver pronta no momento da reconciliação, tenta baixá-la na hora.
- Se ainda estiver invoice_pending, o watcher de etiqueta continua verificando a cada ~15 s.
- Não cria uma segunda linha do mesmo SKU/pedido: a linha manual é vinculada antes da
  importação API e passa a ser atualizada pela combinação Pedido + SKU.

SERVIDOR
- O reconciliador roda em thread própria na VPS.
- Funciona de madrugada, fim de semana e com todos os computadores desligados.
- Primeira tentativa ocorre poucos segundos após o serviço subir.
- Full continua ignorado.
