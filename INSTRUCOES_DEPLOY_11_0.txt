ATUALIZAÇÃO NOROMAK EXPEDIÇÃO 11.0 — DEPLOY
============================================

O ZIP é uma atualização por sobreposição. Ele não contém banco SQLite, .env,
backups, segredos do QZ, arquivos de migração nem a pasta .git.

1. Na máquina usada para publicar, confirme que está na pasta atual do projeto:

   git status

   Se houver trabalho ainda não salvo, faça o commit correspondente antes de
   copiar esta atualização. Não descarte alterações locais.

2. Extraia o conteúdo do ZIP dentro da pasta atual do projeto. Preserve a pasta
   oculta .git e não substitua o arquivo .env da instalação.

3. Confira e publique pelo fluxo já existente:

   git status --short
   git add -A
   git commit -m "adiciona edicao persistente de EAN nos pedidos"
   ./publicar.sh

4. Verifique a resposta da aplicação:

   ssh expedicao "curl -fsS http://127.0.0.1:8100/expedicao/api/health"
   ./verificar_servidor.sh

   A API deve responder com version 11.0. O publicar.sh também reinicia o
   serviço expedicao e valida o endereço público.

5. No navegador, abra:

   https://noromakweb.com.br/expedicao/admin

   Faça Ctrl+F5 uma vez. Em Pedidos pendentes, confirme a nova coluna
   Código de Barras / EAN e teste uma alteração em um pedido de homologação.

ROLLBACK
--------
Como a atualização não altera o esquema do banco, o rollback de código pode ser
feito com um novo commit que reverta o commit acima e uma nova execução de
./publicar.sh. Não use git reset --hard na pasta de produção.

OBSERVAÇÕES
-----------
- O banco permanece em /home/expedicao/dados/expedicao.db.
- Os backups permanecem em /home/expedicao/backups.
- Não execute instalar_servidor_uma_vez.sh em uma VPS já configurada.
- A ação Salvar altera só o pedido pendente.
- A ação Banco altera também todos os cadastros do mesmo SKU, mas somente após
  a confirmação explícita exibida na tela.
