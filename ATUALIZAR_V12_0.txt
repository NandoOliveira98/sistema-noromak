ATUALIZAÇÃO 12.0

1. Instale e abra o Zebra Browser Print no computador conectado à Zebra USB.
2. Atualize/publice o sistema:
   git status
   git add -A
   git commit -m "integra Zebra Browser Print na impressao USB"
   ./publicar.sh
3. Faça Ctrl+F5 no Admin, Conferência e Estação Zebra.
4. Abra https://noromakweb.com.br/expedicao/estacao-impressao no PC da Zebra.
5. Se o Browser Print solicitar autorização para noromakweb.com.br, permita.
6. Se a conexão HTTPS local não funcionar, use o link "Abrir suporte SSL local" na Estação e aceite/instale o certificado conforme o Browser Print orientar.
7. Selecione a Zebra USB e clique "Imprimir teste".
8. Deixe a Estação aberta para receber impressões enviadas pelo celular.

Não é necessário instalar QZ Tray nem Noromak Print Service para este fluxo.
