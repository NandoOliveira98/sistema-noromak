VERSÃO 12.4 — NORMALIZAÇÃO DE SKU DA API MERCADO LIVRE

- SKU vindo da API do Mercado Livre agora remove somente prefixo numérico antes do primeiro hífen.
- Exemplo: 155172-ACP429/9-B -> ACP429/9-B.
- Hífens internos são preservados: 155172-ABC-123-X -> ABC-123-X.
- Se o trecho anterior ao primeiro hífen não for somente numérico, o SKU não é alterado.
- Regra aplicada somente à API Mercado Livre (automático, Shipments e sincronização manual).
- O SKU original completo continua salvo em SkuOrigemImportacao para rastreabilidade.
- Ao sincronizar novamente um pedido já importado com o SKU antigo completo, o sistema reconhece a mesma linha e corrige o SKU sem duplicar.
- O cruzamento com Banco de Produtos/EAN passa a usar o SKU normalizado.
