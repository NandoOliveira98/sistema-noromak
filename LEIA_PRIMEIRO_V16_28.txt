NOROMAK V16.28 - PROMOCOES ML / FALLBACK POLICYAGENT

Correcao para erro:
PA_UNAUTHORIZED_RESULT_FROM_POLICIES / HTTP 403 / PolicyAgent

Novo fluxo:
1. Tenta consultar as campanhas gerais por /seller-promotions/users/{USER_ID}.
2. Se o Mercado Livre bloquear essa rota com 403 PolicyAgent, o sistema entra automaticamente em fallback.
3. O fallback lista os anuncios ativos do vendedor.
4. Para cada anuncio, consulta /seller-promotions/items/{ITEM_ID}?app_version=v2.
5. Cruza as promocoes encontradas com Precificador/Apollo normalmente.

A tela continua SOMENTE LEITURA. Nenhuma promocao e aceita, removida ou alterada.

Na tela, o status informa qual fonte foi usada:
- consulta por campanhas
- consulta por anuncio (fallback)

Se o Mercado Livre tambem bloquear as consultas individuais, a tela exibira o aviso de que a autorizacao do aplicativo precisa liberar Seller Promotions.
