VERSÃO 13.8 — CURVA DO APOLLO + SALVAMENTO AUTOMÁTICO

CURVA
- O Precificador agora aceita automaticamente o campo "curva" retornado pela API.
- Também aceita os nomes alternativos "curva_abc" e "abc".
- Valores válidos: A, B, C ou D.
- Se a API atual do Apollo não enviar esse campo, a curva permanece como estava.

SALVAMENTO AUTOMÁTICO
- Alterações no produto são salvas automaticamente após ~900 ms sem digitação.
- Funciona para SKU, Produto, Custo, Imposto, Curva e configurações dos marketplaces.
- Também funciona para composição de kits quando os dados estiverem válidos.
- Produto novo é criado automaticamente assim que existir SKU válido e os dados necessários.
- Evita duplicar produto novo com o mesmo SKU.
- O botão manual continua disponível como "Salvar agora".
- A tela mostra o status do salvamento automático e horário do último salvamento.

INTEGRAÇÃO APOLLO
- Custo médio continua automático.
- Descrição continua automática.
- Curva será automática assim que o endpoint fornecido pelo Apollo/CRM passar a retornar esse campo.
