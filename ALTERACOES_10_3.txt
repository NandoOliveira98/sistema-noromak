SISTEMA DE CONFERÊNCIA NOROMAK — VERSÃO 10.3

NOVA IMPORTAÇÃO DO RELATÓRIO DE VENDAS DO MERCADO LIVRE

- Novo botão “Importar relatório Mercado Livre” na tela Pedidos pendentes.
- Aceita o relatório oficial de Vendas baixado do Mercado Livre, mesmo com linhas informativas antes do cabeçalho.
- Detecta automaticamente a linha dos cabeçalhos.
- Cruzamento de campos:
  N.º de venda -> Pedido
  Data da venda -> Data do Pedido
  Comprador -> Cliente
  SKU -> SKU/produto
  Unidades -> Quantidade
  Título do anúncio -> Descrição
- Quando o SKU é encontrado no banco de produtos, completa automaticamente EAN, descrição, rua, módulo, prateleira, nível, posição e foto.
- Também tenta resolver SKUs do Mercado Livre que contenham prefixos/sufixos antes do SKU interno, reaproveitando a mesma lógica da importação por print.
- Mantém o número completo 20000... internamente, ocultando o prefixo na tela como antes.
- Pedidos já pendentes são atualizados sem apagar quantidades já conferidas.
- Pedidos concluídos que forem importados novamente continuam usando o histórico/tag “JÁ FOI FEITO”.
- Nenhum pedido pendente que não esteja no relatório é excluído.
- Todas as funções existentes da versão 10.2 foram preservadas.
- Quando o relatório traz uma linha “Pacote de X produtos”, as vendas seguintes marcadas como pacote são agrupadas sob o Pack ID, mantendo todos os SKUs/quantidades no mesmo pedido físico para casar com a etiqueta do Mercado Livre.
