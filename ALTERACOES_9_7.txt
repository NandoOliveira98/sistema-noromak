VERSÃO 9.7 — ETIQUETAS PERSISTENTES NO SERVIDOR

- As etiquetas já processadas não são mais substituídas quando um novo arquivo é anexado.
- O banco de etiquetas permanece no servidor SQLite e é compartilhado entre todas as máquinas.
- A aba Etiquetas agora mostra Mercado Livre, Magalu e Shopee com todas as etiquetas armazenadas.
- Cada etiqueta possui um botão × para remoção manual individual.
- A remoção é sincronizada com as outras máquinas e com a tela de Conferência.
- Se uma etiqueta vinculada for removida, o pedido deixa de aparecer como disponível até receber outra etiqueta.
- Arquivos repetidos não duplicam etiquetas já armazenadas.
- A seleção do campo de arquivo é limpa após o processamento, mas as etiquetas continuam visíveis na lista fixa do servidor.
- Mantidas as funcionalidades da versão 9.6, inclusive alerta sonoro reforçado.

OBSERVAÇÃO
Os campos nativos “Escolher arquivos” do navegador não podem manter um arquivo selecionado após atualizar a página por regra de segurança do navegador. Por isso, após PROCESSAR E VINCULAR, as etiquetas passam a aparecer na nova lista “Etiquetas armazenadas no servidor”, que é persistente e compartilhada.
- O servidor também mescla alterações concorrentes do banco de etiquetas para reduzir risco de uma máquina sobrescrever a inclusão/remoção feita em outra.
