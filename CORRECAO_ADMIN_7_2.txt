CORREÇÃO 7.2 — ACESSO AO PAINEL ADMINISTRATIVO

Problema corrigido:
- O botão do painel administrativo abria /admin.html na raiz do domínio.
- Como o sistema é publicado sob /expedicao, o navegador saía do aplicativo e recebia 404.

Comportamento novo:
- O botão abre /expedicao/admin quando publicado no NoromakWeb.
- Em teste local, continua abrindo /admin.
- Também foi incorporada a correção de host 127.0.0.1.

Publicação:
  git add -A && git commit -m "corrige acesso ao painel admin"
  git push producao master
  ssh expedicao "sudo systemctl restart expedicao"
